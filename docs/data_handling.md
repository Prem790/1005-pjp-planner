# Assignment data handling

The supplied workbook, briefs, simulator, and derived record-level results are
for this assignment only. They stay local under `data/private/` and
`artifacts/`, both ignored by Git. The source originals remain in Downloads;
this setup copies rather than moves or changes them.

Only reusable code, generic method specifications, configuration, and project
documentation belong in version control. Do not paste dealer records, local
reports, coordinates, or source documents into GitHub issues or pull requests.
Code files should not embed sample dealer rows or authentic coordinates.

The local simulator is copied without modification and excluded from Git.
Do not use its hidden/revealed events as inputs to live re-planning. Practice
seeds are evaluation inputs; the implementation must generalize.

Provide confidential results to the assignment reviewers only through an
appropriate private delivery channel. This repository does not publish or
send any files. At completion, remove local confidential copies and derived
outputs as required by the assignment, including original Downloads files
when authorized by the user. No automatic deletion is performed.
